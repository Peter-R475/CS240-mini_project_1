Machine Learning Engineer

AI MAXIMUS is looking for a Machine Learning Engineer to turn data into practical AI features. You will work with product and engineering teams to prepare datasets, train and evaluate models, and integrate reliable predictions into applications.

Responsibilities:

  • Prepare and validate datasets, build reusable feature pipelines, and document data quality issues.
  • Train and compare machine learning models for classification, regression, and recommendation tasks.
  • Evaluate models with appropriate metrics and investigate overfitting, data leakage, and performance gaps.
  • Collaborate with backend developers to serve model predictions through documented APIs.
  • Track experiments and model versions, monitor deployed performance, and investigate changes in input data.
  • Communicate model limitations and trade-offs clearly to technical and non-technical teammates.

What we would like to see:

  • A degree in Computer Science, Data Science, Engineering, or equivalent practical experience.
  • Working knowledge of Python, pandas, NumPy, and scikit-learn.
  • Understanding of statistics, train/test splits, cross-validation, and common evaluation metrics.
  • Familiarity with a deep learning framework such as PyTorch or TensorFlow is a plus.
  • Experience with Git and an interest in reproducible experiments and maintainable code.
  • A portfolio or project showing how you solved a practical problem with machine learning.

Salary range and compensation:

Negotiable based on skills and experience.

Benefits:

  • Learning support for AI courses, technical books, and relevant workshops.
  • Access to development tools and compute resources for approved projects.
  • Flexible working arrangements agreed with the team.
  • Mentorship, code reviews, and opportunities to contribute to real product features.
