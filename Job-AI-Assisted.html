AI-Assisted Web Developer

NexGen Innovations is looking for a talented Frontend Developer who is highly proficient in modern web technologies (HTML5, CSS3, JavaScript) and enthusiastic about adopting AI Coding Tools (such as GitHub Copilot, Cursor, ChatGPT, Claude, V0) to exponentially boost coding speed, accuracy, and workflow efficiency. You will collaborate with our design and backend teams to build stunning, responsive, and seamless user experiences.

Responsibilities:

  • Design and write clean, high-performance client-side code using HTML5, CSS3, and ES6+ JavaScript, translating Figma designs into interactive interfaces
  • Leverage AI coding assistants across all phases (generation, debugging, refactoring, and unit testing) to reduce repetitive tasks and optimize development cycles
  • Develop fully responsive layouts for mobile, tablet, and desktop, adhering to WCAG accessibility standards.
  • Partner with Backend Developers to consume APIs via JSON, and sync with PM and QA teams to maintain code standards.
  • Optimize assets and web architectures to maximize page speed and achieve a Lighthouse Performance Score of 85+
  • Diagnose, debug, and resolve cross-browser compatibility issues to keep frontend applications modern and stable.

What we would like to see:

  • Bachelor's degree in Computer Engineering, Computer Science, IT, or equivalent experience with a stellar web development portfolio.
  • Advanced proficiency in HTML5, CSS3, and JavaScript (Vanilla & ES6+)
  • Familiarity with modern CSS Frameworks (e.g., Tailwind CSS, Bootstrap).
  • Mastery of AI-powered development tools (e.g., GitHub Copilot, Cursor, Tabnine, ChatGPT, Claude).
  • Strong understanding of Git version control and collaborative platforms like GitHub or GitLab.
  • A proactive mindset with a strong passion for integrating AI into daily engineering workflows.

Salary range and compensation:

40,000 -70,000 THB/monthly depending on skills and experience

Benefits:

  • Free Pro licenses for essential AI tools (GitHub Copilot, Cursor Pro, ChatGPT Plus, etc.)
  • Premium health and dental insurance
  • Retirement plan (provident fund) with special company matching rates
  • Activity areas, fitness classes, and corporate sports club access
